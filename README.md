# ![](https://user-images.githubusercontent.com/4441470/224455560-91ed3ee7-f510-4041-a8d2-3fc093025112.png) Soenneker.Vcruntime.Library
### Bundled Microsoft Visual C++ runtime libraries for Windows x64 applications.

## Installation

```
dotnet add package Soenneker.Vcruntime.Library
```

The file is copied to the output directory, and located at the relative path: `Resources\`.
